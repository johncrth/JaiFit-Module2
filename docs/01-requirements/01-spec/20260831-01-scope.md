> เติมตามคู่มือ `homework-scope-guide.md` — ใช้ตารางนี้ต่อทั้งการบ้านที่ 2 · 3 · 4

## ประโยคเดียวของระบบ

ระบบของฉันเก็บ **บันทึกการกินอาหาร (mealLog)** ที่ **ผู้ใช้แอป** สร้างขึ้น
แต่ละบันทึกเลือก **หมวดอาหาร (foodCategory)** ได้ และมีสถานะ **ปลอดภัย (safe) → เสี่ยง (risky) → เกินโควต้า (exceeded)**
โดย **ระบบ AI (nudge engine)** เป็นคนประเมินและส่งคำแนะนำ (nudge) เปลี่ยนสถานะ

## ตารางขอบเขต

| | 🔧 LeaveEasy | 👤 JaiFit (ของฉัน) |
|---|---|---|
| 📁 โฟลเดอร์หลัก | `leaveRequests` | `mealLogs` |
| 📁 โฟลเดอร์ประเภท | `leaveTypes` | `foodCategories` |
| 📁 โฟลเดอร์ย่อย | `approvals` | `nudges` |
| ✏️ ช่องบอกว่าเป็นของใคร | `requesterId` · `requesterName` | `userId` · `userName` |
| 🔀 สถานะทั้งหมด | รอพิจารณา · อนุมัติ · ไม่อนุมัติ | `safe` · `risky` · `exceeded` |
| 👤 คนที่สร้างรายการ | พนักงาน | ผู้ใช้แอป |
| 👤 คนที่เปลี่ยนสถานะ | หัวหน้า | ระบบ AI (nudge engine) |
| 📝 ช่องข้อความยาวที่ AI จะอ่าน | `reason` | `description` |
| 🤖 งานที่ AI ช่วย (สัปดาห์ที่ 8) | จัดประเภทการลาให้อัตโนมัติ | วิเคราะห์ mealLog แล้วส่ง nudge เตือนผู้ใช้ |

## โครงสร้าง Firestore

```
📁 users/          📄 { name, email, currentPhase, startDate }
📁 foodCategories/ 📄 { name, carbLevel: low/medium/high }
📁 mealLogs/       📄 { title, description, loggedAt, status: safe/risky/exceeded,
                        userId, userName, foodCategoryId, foodCategoryName }
                      📁 nudges/ 📄 { message, sentAt, response }
```

**ช่องที่จดชื่อซ้ำ (denormalize):** `userName` และ `foodCategoryName` ใน `mealLogs`
เพื่อไม่ต้อง JOIN ตอนแสดงหน้ารายการ
