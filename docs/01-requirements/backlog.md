## นอกขอบเขต MVP (Backlog สำหรับเฟสถัดไป)

- เชื่อมต่อ wearable/CGM สำหรับข้อมูลชีวภาพ
- **Native Mobile App (iOS/Android)** — ใช้ Web App responsive แทนใน MVP นี้ อาจพิจารณาขยายในเฟสถัดไปโดย backend/API คงหลักการแยกอิสระจาก frontend ไว้รองรับ (ดู spec หัวข้อ 5)
- ปรับ phase แบบ dynamic ตามอาการจริงของแต่ละคน (ยกเว้นกลไกผ่อนปรนช่วงวันที่ 1-7 ตาม Epic 13 ซึ่งอยู่ใน scope แล้ว)
- ระบบชำระเงิน/สมาชิกแบบเสียเงิน (Account Signup & Login แบบไม่เสียเงินอยู่ใน scope แล้วตาม Epic 11)
- LINE Official Account / LINE Messaging API — ยกเลิกใช้แล้วหลัง pivot ไป Web App (ดู [[01-spec/20260827-01-jaifit-ai-coach-metabolic-transition|spec]] หัวข้อ 1)

ปิด Open Questions 12/13 ข้อของ spec ต้นทาง (ดู [[../05-log/20260829-log|log 2026-08-29]]) — ผลกระทบต่อ backlog: E2-04 เลื่อนจาก Could เป็น **Should** (เพราะ default lead time อัตโนมัติกลายเป็นส่วนหนึ่งของ flow หลักแล้ว, การปรับเองยังเป็นส่วนเสริม), เพิ่ม **Epic 12 (Chronic Condition Screening)** และ **Epic 13 (Adaptive Symptom Easing)** เป็น Must เกือบทั้งหมดเพราะกระทบความปลอดภัยของ user โดยตรงจากตาราง phase (10.4 เดิม), ปรับถ้อยคำ E11-01/E11-02 ให้รองรับ Google Sign-In + JWT ตาม FR11 ที่อัปเดต — E6-04 (เปลี่ยนโหมดภายหลัง) และ E9-04 (นับ streak ใหม่แบบไม่ตัดสิน) คง priority เดิม เพราะเป็นรายละเอียดเสริมที่ยังพอเลื่อนได้

## ทบทวน Priority MoSCoW (2026-08-28)

เพิ่ม insight ใหม่ 3 เรื่อง (โหมดความเข้มข้น, ความหลากหลายของข้อความ, การเตือนล่วงหน้า) และ Reward System เข้ามาเป็น **Must** เกือบทั้งหมด เพราะเป็น insight จากประสบการณ์จริงของผู้ก่อตั้งที่ระบุว่ากระทบการล้มเลิกกลางทางโดยตรง — ยกเว้น E6-04 (เปลี่ยนโหมดภายหลัง) และ E9-04 (นับ streak ใหม่แบบไม่ตัดสิน) ซึ่งเป็นรายละเอียดเสริมที่ยังพอเลื่อนได้ถ้า MVP ต้องตัดขอบเขต

**อัปเดตรอบ 2 (2026-08-28):** เพิ่ม Epic 10 — Motivation Profiling เป็น **Must** สำหรับ E10-01 ถึง E10-03 เพราะเป็นข้อมูลตั้งต้นที่ FR3 (phase tone), FR4 (ให้กำลังใจ), FR9 (reward) ต้องใช้ปรับความหนักเบาของการสื่อสาร — E10-04, E10-05 เป็น Should เพราะเป็นรายละเอียดเสริมที่ปรับปรุงคุณภาพการสื่อสารแต่ระบบยังทำงานหลักได้แม้ยังไม่มี

**อัปเดตรอบ 3 (2026-08-28 — Pivot ช่องทางเป็น Web App):** เพิ่ม Epic 11 — Account Signup & Login เป็น **Must** ทั้งหมด เพราะเป็นโครงสร้างพื้นฐานที่จำเป็นให้ Web App ทำงานได้เลย (แทน LINE user ID ที่ระบุตัวตนอัตโนมัติ) — Epic 1-10 เดิมยังคง priority เท่าเดิมทุกตัว เพราะ pivot นี้เปลี่ยนแค่ช่องทาง ไม่เปลี่ยน priority ของแนวคิดฟีเจอร์
